# checkParavola

Εφαρμογή για επαλήθευση παραβόλων ΚΠγ. Εφόσον κάθε υποψήφιος έχει δικό του φάκελο
της μορφής "<αριθμός> <επώνυμο> <όνομα>" και μέσα στο φάκελο τοποθετούνται τόσο
τα δικαιολογητικά του υποψηφίου όσο και η πληρωμή του παραβόλου
(viewParavolo*) και το δελτίο εξεταζομένου (KPG-Deltio*) κάνει τους παρακάτω
ελέγχους:

- Αν υπάρχουν τα βασικά δικαιολογητικά (\*_ΠΑΡΑΒΟΛΟ, \*_ΤΑΥΤΟΠΡΟΣΩΠΙΑ)
- Αν υπάρχουν τα αρχεία πληρωμής παραβόλου και το δελτίο εξεταζομένου
- Αν το αρχείο του παραβόλου δεν περιέχει τη λέξη ΔΕΣΜΕΥΜΕΝΟ
- Αν τα στοιχεία του παραβόλου δεν ταιριάζουν με τα στοιχεία του δελτίου
- Αν έχει παραπάνω από μια γλώσσα δηλωμένη αν υπάρχουν όλα τα απαραίτητα παράβολα

## Εγκατάσταση απαιτήσεων

```bash
poetry install
```

## Εκτέλεση

Για να τρέξουμε το πρόγραμμα απαιτείται python3 και η εντολή είναι:

```bash
poetry run checkparavola -d <φάκελος με υποφακέλους υποψηφίων>
```
